The AdventureWorks Executive Sales Intelligence Dashboard is a user-friendly Power BI report that transforms raw SQL Server data into clear, interactive sales analytics. Built for quick executive decision-making, the tool features a main screen for tracking global financial performance, an interactive chart to switch views between revenue and order volumes, and automated rankings of top-selling products. To run it locally, you simply restore the database backup file to your local SQL Server instance, open the project file in Power BI Desktop, and update the server connection path to your localhost.
